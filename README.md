# inFocus — Telegram Mini App

Веб-приложение для Telegram Mini App (React + Vite + TypeScript).
Дизайн-источник: Figma «Mini-apps».

## Что готово

- **Онбординг** — 5 экранов (без логина).
- **Главная** — стрик + календарь серии (точки на отмеченных днях, тап по дню → детали).
- **Ввод дня** «День N» — 3 привычки + настроение + мысль дня.
- **Результат** дня — хороший / нормальный / плохой.
- **Детали дня** — разбивка по тапу в календаре.
- **Мой прогресс** — статистика (серии, всего дней, распределение).
- **Профиль** — аватар, история, настройки пушей, нативный баннер, выход.
- Telegram WebApp SDK (`telegram-web-app.js`): `ready/expand`, тема, haptic, данные юзера.
- **Хранение по пользователю** — Telegram CloudStorage (синхронизация между устройствами юзера), фолбэк на `localStorage` вне Telegram. Записи по календарным датам (ключ `d_YYYY-MM-DD`).
  - Лимит CloudStorage: ≤1024 ключей → потолок ~1024 дня (≈2.8 года ежедневных записей). При приближении — компактить старые месяцы в архивные ключи (отдельная задача).

## Запуск

```bash
npm install
npm run dev
```

Откроется на http://localhost:5173.
Вне Telegram приложение работает как обычный сайт (SDK деградирует мягко).

## Тест внутри Telegram

1. Подними публичный URL (через `npm run dev -- --host` + туннель, напр. `ngrok http 5173`, или задеплой `npm run build` → хостинг).
2. В @BotFather: создай бота → Mini App / кнопку меню → вставь HTTPS-URL.
3. Открой бота — Mini App запустится внутри Telegram.

## Структура

```
src/
  main.tsx              — точка входа, init Telegram
  App.tsx               — роутинг: онбординг / главный экран
  onboarding/
    Onboarding.tsx      — компонент онбординга (5 шагов)
    steps.ts            — тексты экранов из Figma
    Onboarding.css
  lib/
    telegram.ts         — обёртка Telegram WebApp SDK
    storage.ts          — localStorage
    useViewportHeight.ts— высота вьюпорта Telegram
  styles/
    tokens.css          — дизайн-токены из Figma
    global.css
```
